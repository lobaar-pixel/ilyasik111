Описание: Программа формирует случайные задачи, сохраняет их историю, распределяет задачи по типам.
Нужно запустить приложение, там будут много кнопок. Сначала выбираете тип задачи, далее пишите описание задания, нажимаете "Сгенерировать новую задачу", программа выдает вам задачу и ее тип. Ниже пишется история задач. Так же задачи можно фильтровать по типу задачи
